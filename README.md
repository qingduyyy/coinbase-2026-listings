# Coinbase 2026 Listings — Dashboard

A self-contained, mobile-responsive dashboard tracking every asset listed on **Coinbase**
since 2026-01-01 (spot + perpetual futures), with per-project insights and side-by-side
comparison.

- **Live:** open `index.html` (also published via GitHub Pages).
- Data is embedded — works offline. Regenerated from the pipeline in the parent research repo.
- Features: search, filter (asset class / stage), sort, tap-for-detail, multi-select compare.

Snapshot: 72 assets (52 crypto + 20 TradFi perps) · 50 spot · 41 perp.
